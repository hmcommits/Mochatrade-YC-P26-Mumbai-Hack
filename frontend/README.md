# MuleNet — Frontend Console & Graph Architecture

A contact-tracing engine for illicit fund flows, featuring:
- **Preserved Marketing Web Layer (`/`)**: Dark theme, typography (`Space Grotesk`, `Space Mono`, `Inter`), interactive hero topology animation, problem, approach, technical architecture, and RBI SOP compliance sections.
- **Enterprise Analyst Dashboard (`/app/*`)**:
  - **Overview (`/app/overview`)**: Live heterogeneous network graph with custom force simulation, risk threshold filter slider, account search, reset layout, investigate now button, and active investigation dossiers.
  - **Alerts (`/app/alerts`)**: Incident queue with triage filters and one-click RBI SOP freeze initiation.
  - **Transactions (`/app/transactions`)**: Searchable multi-party ledger with zero-dwell transit velocity tags.
  - **AI Insights (`/app/ai-insights`)**: Heterogeneous GNN embeddings, dwell comparisons, and GNNExplainer feature attribution matrix.
  - **Watchlist (`/app/watchlist`)**: Active surveillance tracking for accounts, device fingerprints, and suspicious subnets.
  - **Reports (`/app/reports`)**: RBI Standard Operating Procedure freeze requests & SHA-256 evidence packages.
  - **Case Management (`/app/cases`)**: Lifecycle stage tracker from flag to freeze.
  - **Data Ingestion (`/app/input`)**: CSV dropzone, 1-click synthetic mule dataset, schema validator, preview table, and 7-step pipeline animation modal.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
